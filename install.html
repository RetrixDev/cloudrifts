Install guide

Install Cloudrifts on Ubuntu 24.04.

Use a fresh x86_64 VPS with root or sudo access. The bootstrap script verifies the pinned release checksum before running the bundle installer.

One-line install

curl -fsSL __GIST_RAW_INSTALL_URL__ | sudo bash

Repository mirror

curl -fsSL https://raw.githubusercontent.com/RetrixDev/cloudrifts/main/install.sh | sudo bash

After install

Open the one-time setup URL printed by the installer, enter your own panel domain such as panel.example.com, choose external DNS or managed DNS, then create your first WordPress, WooCommerce, or PHP website.

Useful commands

systemctl status cloudriftsd
journalctl -u cloudriftsd -n 120 --no-pager
cloudriftsctl status --addr http://127.0.0.1:8080
cat /var/lib/cloudrifts/last-setup-url.txt
