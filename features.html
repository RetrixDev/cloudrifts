Feature status

Focused Phase 1 server management.

Cloudrifts is built for one fresh Ubuntu 24.04 VPS with real website provisioning, server roles, diagnostics, files, logs, backups, DNS, and recovery jobs.

Websites

WordPress, WooCommerce, and PHP provisioning with Linux users, document roots, PHP-FPM pools, MariaDB database setup, and app install jobs.

SSL and DNS

DNS preflight, Let's Encrypt attempts, retry jobs, required record hints, optional PowerDNS managed zones, and registrar delegation guidance.

Operations

File manager, log viewer, local backups, privileged restore, server role status, webserver switching, activity, and job trails.

Current boundaries

Full mailbox management, DKIM/DMARC automation, remote backup providers, multi-server clusters, and complete production team permissions are not presented as finished features in this public preview.
