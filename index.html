Built for people searching for a hosting control panel, VPS control panel, WordPress hosting panel, PHP hosting panel, cPanel alternative, CyberPanel alternative, or CloudPanel-style single-server panel.

What it controls

Real server workflows, visible from the panel.

01

Provision websites

Create WordPress, WooCommerce, or PHP sites with Linux users, document roots, PHP-FPM pools, MariaDB credentials, webserver vhosts, and app install jobs.

02

Repair SSL faster

Run DNS preflight, see exact required records, attempt Let's Encrypt, and retry SSL from diagnostics after records resolve.

03

Operate the server

Track Nginx, Apache, PHP-FPM, MariaDB, optional PowerDNS, and optional Postfix/Dovecot role setup from one workspace.

04

Recover with context

Browse files, edit content, read logs, create local backups, restore safely, and inspect the job trail behind each operation.

Why Cloudrifts

Not just buttons. Jobs with proof.

Every major action is represented as a backend job with steps, issues, logs, and recovery hints. That makes the panel practical for real VPS administration, where DNS, services, certificates, files, and package state often need precise feedback.

Install

One command on a fresh VPS.

The bootstrap installer downloads the pinned GitHub release bundle, verifies SHA256, extracts it, and runs the real Cloudrifts installer. The installer prints a private one-time setup URL for your browser.

Open the full install guide
cloudrifts install
