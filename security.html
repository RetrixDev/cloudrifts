Security

Test Cloudrifts with care.

Cloudrifts controls real server services and files. The current release is an early public test build for fresh Ubuntu 24.04 servers.

Recommended use

Use a fresh VPS, keep the one-time setup URL private, review open ports, prefer trusted IP access during evaluation, and put the panel behind HTTPS for real use.

Current model

The browser panel talks to cloudriftsd. Privileged operations go through cloudrifts-agent with a narrow sudoers policy created by the installer.
